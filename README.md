## Overview

This repository documents my hands-on practice with HTML5 and the fundamentals of web development. It serves as a collection of coding exercises and practical implementations as I work toward writing clean, accessible, and well-structured markup.

My focus is on understanding core concepts, applying them through practice, and building the foundation needed to develop modern web experiences.

## Focus Areas

- Semantic HTML and accessible page structure
- Headings, text formatting, links, and media
- Lists, tables, and forms
- Clean, readable, and maintainable markup
- Consistent coding practice and version control
